
Variable Declaration and Initialization

To create a variable, you specify its data type followed by its name. You can assign a value at the time of creation (initialization) or do it later.
java
// Declaration only
int speed; 

// Initialization
speed = 100; 

// Declaration and initialization together
String greeting = "Hello, World!";

Naming Rules (Identifiers)

When naming your variables in Java, you must follow these strict syntax rules:
• Allowed Characters: Names can contain letters, digits, underscores (_), and dollar signs ($).
• Starting Character: Names cannot start with a digit. They must begin with a letter, _, or $.
• No Reserved Words: You cannot use Java keywords (like int, class, public, or if) as variable names.
• Case-Sensitivity: Java treats myVar and myvar as completely separate variables.
• No Spaces: Spaces are strictly forbidden within a variable name.
